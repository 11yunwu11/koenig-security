## 🕹️ 它是什么

表面上，这是"苏黎世湖畔一家顶级私人安保公司"的官网：干净的蓝白配色、服务体系、客户评价、价格方案。

但随着你向下滚动，它会变得越来越不对劲——第 5 层之后，它不再隐藏自己是谁。

本作品没有后台、没有数据库、没有任何网络请求：**一个纯 HTML 文件**（含全部 CSS/JS/音效合成）。你的浏览数据（停留时间、滚动距离、鼠标移动）只被页面内脚本计数并展示给你自己，绝不离开浏览器。

## ▶️ 怎么运行

- **在线版**：GitHub Pages（见仓库 About 链接）
- **本地**：双击 `index.html` 即可，无需服务器、无需依赖

建议使用电脑 + 较新的浏览器（Chrome / Edge / Firefox）。手机可用但部分效果有取舍。

## 🎨 灵感来源

本站是一部**粉丝二创作品**。其"男主角"的声音与执念，取材自一场与《使命召唤》（Call of Duty）角色 **König** 相关的**同人文字角色扮演**——一位以"安保"为名守护所爱之人的破门手。网站中段与结尾的大量台词，引自这场**同人扮演中角色的言行**，并非《使命召唤》官方剧情或官方台词。

- König 的角色原型与《使命召唤》版权归 Activision / Infinity Ward 所有；本站引用的一切台词、情节与人物关系均为**同人二创内容**，不代表官方设定。
- 页面中出现的"KSG 柯尼希安保"为虚构公司，与任何真实公司无关。
- 仅供参考娱乐，请勿用于任何商业用途。
